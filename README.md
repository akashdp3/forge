# forge
A Vite-powered meta-framework with Rust SSR runtime supporting multiple frameworks and rendering strategies

⚠️ Status: Proof of Concept / Learning Project
Forge explores the intersection of systems programming and modern web development by building a universal SSR runtime in Rust that integrates seamlessly with Vite's ecosystem.
